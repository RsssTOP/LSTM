# LSTM VKR (ML Project)

Тема ВКР: построение ML-пайплайна для анализа метрик инфраструктуры с использованием LSTM и transfer learning.

## Датасеты
- Google Cluster Data
- Alibaba Cluster Data
- Bitbrains

## Пайплайн
`Data → LSTM (TL) → Embeddings → Clustering`

## Быстрый старт (локально)
1. Создайте виртуальное окружение и установите зависимости.
2. Подготовьте данные в `data/raw`.
3. Запустите обучение/инференс согласно вашим скриптам.

> Примечание: структура и команды будут уточняться по мере наполнения репозитория.

## Быстрый старт (Docker)
1. Соберите образ: `docker build -t lstm-vkr .`
2. Запустите контейнер: `docker run --rm -it -v $(pwd):/app lstm-vkr`

> Примечание: Dockerfile будет добавлен вместе с кодом пайплайна.
